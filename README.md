# Electricity_load_forecasting
**PJM Electricity Load Forecasting Using XGBoost**

Developed a machine learning-based time-series forecasting system to predict hourly electricity demand using historical PJM energy consumption data. Implemented data preprocessing, exploratory data analysis (EDA), and feature engineering to identify energy consumption trends and patterns. Built an XGBoost regression model for electricity load prediction and integrated the trained model into a Streamlit web application for interactive forecasting. The project aims to support efficient energy management, demand planning, and power resource optimization.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Streamlit, Time-Series Analysis.
